My New Project: E-Commerce API

I’m excited to share that I’ve recently built a new backend project — a fully functional E-Commerce API developed using ASP.NET Web API.

🔑 Key Features

1. Onion Architecture:
Clear separation of concerns to improve maintainability and scalability.
Separate databases for Models and Identity to streamline data management.

2. Authentication & Authorization:
Implemented JWT for secure user authentication and authorization.

3. Error Handling:
Developed a custom Middleware to handle server errors and other error types, providing clear and structured responses.

4. Generic Repository Pattern & Unit of Work:
Enabled dynamic repository requests, ensuring a cleaner and more efficient data access layer.

5. AutoMapper:
Used AutoMapper for mapping between Models and DTOs, reducing repetitive and error-prone code.

6. Specification Design Pattern:
Enhanced code flexibility and created endpoints supporting filtering, sorting, and pagination for the product model.

7. In-Memory Caching with Redis:
Developed the Basket Model using Redis to improve performance and reduce database load.
